# Payal Motors – Loan Amortization Calculator

A professional, responsive loan amortization calculator built with pure HTML, CSS, and JavaScript.

## Features

- **EMI Frequencies:** Monthly, Half-Yearly, and Annual
- **Interest Methods:** Reducing Balance & Flat Interest
- **Extra Payments:** Optional extra principal with flexible frequency
- **Schedules:** Full period-wise amortization table + Annual summary
- **Customer & Agent:** Name, contact, and agent watermark on results
- **Indian Rupee (₹)** formatting
- No backend, libraries, or login required — works offline in any browser

## How to Use

1. Open `loan-amortization-calculator.html` in Chrome (or any modern browser)
2. Enter Customer Name, Contact, and Agent Name (optional)
3. Fill Loan Amount, Term (Years), and Interest Rate
4. Choose Interest Method and EMI Frequency
5. Optionally enable Extra Payments
6. Click **Calculate ▶**

## Default Example

| Field | Value |
|-------|-------|
| Loan Amount | ₹2,00,000 |
| Term | 15 Years |
| Interest Rate | 6% |
| Method | Reducing Balance |
| Frequency | Half-Yearly EMI |
